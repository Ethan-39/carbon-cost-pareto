# Carbon Cost Pareto

Standard-library Python demo that compares fictional annual energy scenarios across cost, emissions, and a relative comfort penalty, then reports the Pareto frontier. It compares assumptions and does not choose or control an option.

```bash
python carbon_cost_pareto.py
python -m unittest discover -s tests -v
```

Full Chinese documentation and assumptions: [README.zh-CN.md](README.zh-CN.md).
